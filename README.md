## 🛠️ What is TankStream?

TankStream will be a low-latency, peer-to-peer media bridge designed to stream local webcam video and microphone audio across local networks using **WebRTC** and **hardware-accelerated encoding**.

## 🚧 Development Roadmap (v0.1.0 Goals)

This repository is in its initial setup stage. Here is what is currently being built for the initial working release:

- [ ] WebRTC peer-to-peer signaling & connection engine
- [ ] Hardware-accelerated video encoding pipeline (NVENC / QuickSync / VAAPI)
- [ ] Low-latency Opus audio stream pipeline
- [ ] LAN auto-discovery mechanism
- [ ] Basic CLI interface for peer pairing
